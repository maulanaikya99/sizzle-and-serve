Sizzle &amp; Serve is a short-shift kitchen game: read the order board, grab from the pantry, chop
on the block, cook on the stove, plate the finished pieces and serve before the clock runs out. It
runs entirely in a desktop browser from static files, with no build step and no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

The game is under `game/`, played with the mouse and the keys 1&ndash;7. `main.ts` hands the entry in:
it copies `game/` and `screenshots/` to `/output` and writes `dossier.json`.
